# GenU card renderer

The script that draws GenU cards inside OpenClaw chat widgets. Load a pinned version from jsDelivr:

```html
<script>globalThis.genuBoot = { card, icons };</script>
<div class="ic"></div>
<script src="https://cdn.jsdelivr.net/gh/josephux/genu-renderer@1.0.0/genu.min.js" integrity="sha384-KjxxpN3izec4Uz/fbbmFARgXK/hFsg0uO8eil2q6HEMxoNZlbNJ+XKMuuW9b8Lx1" crossorigin="anonymous"></script>
```
